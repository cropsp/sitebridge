# ТЕХНІЧНЕ ЗАВДАННЯ ДЛЯ АГЕНТА: Розробка Bridge-сайту (Pinterest ➡️ Сайт ➡️ Amazon + Власні товари)

## 📌 Контекст проекту та Стратегія Запуску
Ти — автономний AI-агент розробки. Твоє завдання: спроєктувати та розгорнути оптимізований під SEO "сайт-прокладку" (Bridge Site). 
Головна мета сайту — конвертація "холодного" візуального трафіку з Pinterest у покупців. 
Сайт використовуватиме гібридну модель монетизації: пріоритетний продаж власних фізичних товарів (бренд **Lamamarka**) та додаткова монетизація через партнерську програму **Amazon Associates**.

### 🗓 Таймлайн проєкту (Критично важливо для уникнення банів)
1.  **Місяць 1-2 (Прогрів домену та Pinterest):** Запуск сайту з якісним контентом (Pillar Pages + Cluster Articles). Активний постінг у Pinterest. Всі посилання на Amazon — звичайні заглушки без affiliate-тегів.
2.  **Місяць 3+ (Монетизація Amazon):** Тільки після отримання стабільного трафіку (напр., 100+ кліків/день) відбувається офіційна реєстрація в Amazon Associates. Заглушки автоматично замінюються на партнерські посилання для швидкого виконання умови "3 продажі за 180 днів".
3.  **Постійно (Lamamarka):** Продаж власних товарів активний з першого дня запуску сайту.

## 🏗 Архітектура, Технічний Стек та Вибір Шаблону
*   **Фреймворк:** **Astro** (максимальна швидкість завантаження для мобільного трафіку з Pinterest).
*   **Базовий шаблон (КРИТИЧНО):** Ініціалізувати чистий базовий блог через команду `npm create astro@latest -- --template blog`. *Не імпортувати важкі сторонні теми.*
*   **Контентна база:** Markdown/MDX. Статті повинні зберігатися локально у вигляді чистих файлів для зручної інтеграції та редагування в Obsidian. Синхронізація через Git буде автоматично запускати деплой.
*   **Хостинг та CI/CD:** **Cloudflare Pages** (через адаптер `@astrojs/cloudflare`).
*   **Інтеграція e-commerce:** Заглушка під клієнтський JS для Shopify Buy Button (для Lamamarka); власні UI-компоненти для Amazon.

*   **Ітеративна розробка:** Розгорни мінімалістичне ядро і створюй специфічні товарні компоненти покроково та повністю з нуля.

## 🛡 Стратегія безпеки (Правила Amazon та Pinterest)
**КРИТИЧНІ ПРАВИЛА, порушення яких призведе до бану:**
1.  **Жодних статичних цін Amazon:** Заборонено хардкодити ціни з Amazon у Markdown чи HTML. Компонент посилання повинен мати лише кнопку "Check price on Amazon".
2.  **Глобальний перемикач Affiliate:** Створити `.env` змінну `ENABLE_AMAZON_AFFILIATE=false`. Ця змінна зчитується під час збірки (build-time) через `import.meta.env`. Поки вона `false`, компоненти віддають чисті лінки на Amazon без тегів.
3.  **Легітимність бізнесу (Pinterest Trust):** Обов'язкова наявність сторінок: `About Us`, `Contact`, `Privacy Policy`.
4.  **Affiliate Disclosure:** У футері КОЖНОЇ сторінки має бути чітке повідомлення про партнерські посилання.
5.  **SEO Метадані:** Обов'язкова підтримка OpenGraph та Twitter Cards, а також розмітки `Schema.org` (Article, Product).

## 🎨 UI/UX та Структура Контенту
Власні товари мають розміщуватись у найвигідніших зонах сторінки (Hero section, закріплені банери). Супутні товари Amazon інтегруються як доповнення.
Агент має розробити такі компоненти:
*   `<ProductCard isOwnProduct={boolean} />` — Якщо `true` (Lamamarka), використовувати компонент-заглушку, куди пізніше буде вставлено iframe/JS код від Shopify Buy Button. Якщо `false` (Amazon) — стриманий дизайн із "Check price".
*   `<ComparisonTable />` — Таблиця порівняння характеристик (без фіксованих цін Amazon).
*   `<PinterestPinBox />` — Блок з оптимізованим зображенням (2:3 співвідношення) та атрибутом `data-pin-description` для стимулювання збереження користувачами.

## 🚀 Покроковий план дій для Агента (Execution Steps)
1.  **Ініціалізація:** Виконай `npm create astro@latest -- --template blog`. Перевір наявність TailwindCSS, встанови його за необхідності офіційною командою інтеграції Astro.
2.  **Інтеграція з Cloudflare:** Налаштуй адаптер `@astrojs/cloudflare` для коректного деплою.
3.  **Типізація контенту (Zod):** Створи файл `src/content/config.ts`. Налаштуй жорсткі схеми для колекцій: додай обов'язкові поля `isOwnProduct` (boolean), `price` (number, опціонально), `affiliateLink` (string, опціонально).
4.  **Розробка UI:** Створи макети сторінок та розробити зазначені вище компоненти з нуля.
5.  **Сторінки довіри:** Згенеруй сторінки About, Contact, Privacy, Disclosure.
6.  **SEO та Метадані:** Реалізуй компонент `<SEO />` для автоматичної підстановки OpenGraph/Schema.org.
7.  **Тестування:** Забезпеч локальний запуск та перевір логіку "заглушок" при `ENABLE_AMAZON_AFFILIATE=false`.
